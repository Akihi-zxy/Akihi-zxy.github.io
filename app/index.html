把网站装进手机

不用下载、不用注册，两分钟把本站添加到手机主屏幕——之后点图标打开就是全屏攻略， 看过的页面没网也能查。 路上过口岸、进帕米尔、坐夜车，信号说没就没，出发前装好最省心。

第 0 步：从微信里跳出来

如果这个页面是在微信里点开的： 微信内置浏览器装不了，先点右上角「···」，选「在浏览器打开」 （iPhone 显示为「在 Safari 中打开」），再按下面的步骤操作。

iPhone

SAFARI
  1. 1用默认浏览器打开 thesilkloop.com（在微信里点开的话，先按上面第 0 步跳出来）
  2. 2点屏幕底部中间的「分享」按钮（一个方框、上面有个向上的箭头）
  3. 3在弹出的菜单里向下滑，找到「添加到主屏幕」
  4. 4右上角点「添加」——桌面上会出现墨黑底的「环线」图标

如果分享菜单里找不到「添加到主屏幕」，换用 Safari 打开本站再操作一遍即可。

安卓

CHROME
  1. 1用 Chrome 或手机默认浏览器打开 thesilkloop.com（在微信里点开的话，先按上面第 0 步跳出来）
  2. 2点右上角「⋮」菜单
  3. 3选「添加到主屏幕」（部分手机显示为「安装应用」）
  4. 4确认后桌面出现「环线」图标

没有 Chrome 也可以：华为、小米等自带浏览器和 UC、夸克大多在菜单里有「添加到桌面」， 位置略有不同，找「⋮」或「≡」菜单即可。

常见问题

占手机空间吗？
几乎不占。它不是从应用商店下载的 App，本体就是个书签图标；离线缓存只保存你看过的页面，图片数量有上限，通常总共几十 MB 以内。不想要了长按图标删除即可，和删 App 一样。
没网的时候能看什么？
你打开过的页面都能看：翻过的城市页、逐日路线、签证速查，到了没信号的口岸、山区照样能查。没打开过的页面需要联网先看一次；天气、汇率这类实时数据也需要联网，断网时会显示离线参考值。
内容会更新吗？
会，自动的。每次联网打开都会拉取最新内容，不需要手动更新，也永远不会弹更新提示。
和普通浏览器打开有什么区别？
内容完全一样。区别是：主屏幕一个图标点开就是，不用记网址；打开后全屏显示、没有地址栏；看过的页面离线可查。
